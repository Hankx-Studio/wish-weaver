## 1. 背景與目標

### 1.1 一句話
**Spirit Companion 是一隻會因你的心意而成長的 AI 精靈伴侶：念出咒語，魔法就變得看得見；累積的善意，能化成真實的物資分享給別人。**

### 1.2 產品核心
- **魔法可視化**：經典奇幻主題，使用者用語音念咒語（祝福、感恩、心意），精靈以光影粒子與可愛的聲音回應。
- **伴侶式 AI**：精靈像寵物一樣存在——會哼唧、會笑、不說人話；靠互動累積 XP 隨機演化。
- **實體交互（願景）**：精靈可以「住進」一個水晶吊墜（Pepper's Ghost 虛像），磁力戒指喚醒，磁懸浮魔法陣充電。
- **社會影響**：互動產生的封閉「精靈幣」，可兌換商家承諾的物資自用或分享給他人。

### 1.3 比賽目標與評分對應

評分權重為非官方資料（參賽者整理之賽事指南），開工時登入 Cerebral Valley 後台核對。

| 評分項（非官方權重） | 本產品對應 | 對應章節 |
|---|---|---|
| Impact 30% | L3 精靈幣 → 物資預約／分享／核銷完整跑通；影片結尾昇華 | §5.5、§11 |
| Meta AI tooling 25% | Muse Spark、Muse Image、SAM 3.1、Muse Code 各有真實用途 | §8 |
| Demo 25%（live＋3 分鐘影片） | 公開網址可登入操作；Demo 快轉；影片三段式 | §5、§11 |
| Technical depth 20% | 原子帳本、即時多人同步、演化素材管線、BLE 協定編碼 | TECH_STACK |

另有 Community Vote（展示頁投票）與 Most Viral（X 貼文互動）——由行銷端負責，工程端只提供錄影素材。

### 1.4 成功指標（比賽期間）
| 指標 | 目標 |
|---|---|
| 評審可在單次操作內完成：孵化 → 念咒 → 粒子回應 → 第一次演化 → 預約並核銷一份物資 | 100%，≤ 10 分鐘 |
| 公開網址於 11/4–11/16 可用率 | 無中斷（含 Supabase keepalive） |
| 每個 Meta 工具至少一條「meta_live」可見因果鏈 | 4/4 |
| Meta API 花費 | ≤ US$150，硬上限保護 |
| 本機實測 | Android Chrome、iOS Safari、桌面 Chrome 全流程通過 |

### 1.5 非目標（本次不做）
- 實體吊墜、戒指、魔法陣的製作與韌體；Web Bluetooth 實連
- iOS／Android 原生 App
- 真實金流（「點數＋現金」折扣包）、硬體 ×1.1 加成
- 兒童模式與監管者
- 中國大陸、港澳市場；中文／日文 UI 上線（僅預留）
- 精靈開口說話（TTS）、自由聊天

## 2. 範圍與真實度分級

所有功能都會出現在作品中，但真實度分三級，介面與影片清楚標示。

| 等級 | 標示 | 定義 | 包含 |
|---|---|---|---|
| ✅ Real | `meta_live` / `local_rule` | 部署在公開網址、評審可親手操作、資料真實寫入 | 語音咒語、意圖判斷、粒子回應、XP、演化生圖、世界上色、吊墜模擬器畫面、共同儀式（真人多機）、精靈幣全流程（Demo 商家）、Google 登入、量化後台 |
| 🧪 Simulated | `demo_fixture` | App 內可操作但明確標示模擬 | 戒指靠近喚醒（按鈕觸發）、BLE 連線與指令傳送、模擬同伴、Demo 商家供給、Demo 時間快轉 |
| 🎬 Concept | 影片標示 "Concept film" | 只在影片中以 Blender＋Muse 生成呈現 | 實體吊墜、磁力戒指、磁懸浮魔法陣充電座 |

**原則**：`demo_fixture` 不得與 `meta_live` 合併計算；模擬產生的點數不進真實帳本。

## 3. 使用者與情境

### 3.1 使用者
| 角色 | 說明 | 本次支援 |
|---|---|---|
| 玩家（成人 18+） | 歐美優先，其次日韓；喜歡療癒、奇幻、寵物養成；想有日常的小儀式感 | ✅ |
| 雙人／好友 | 情侶、朋友一起施法 | ✅（真人＋模擬同伴） |
| 評審 | 單人、時間有限、想快速看到全貌 | ✅（Demo 快轉、完成度看板） |
| 商家店員 | 在手機上核銷領取券 | ✅（Demo 商家帳號） |
| 平台營運（我們） | 看量化數據、控制額度、處理申訴 | ✅（隱藏在設定內的管理頁） |

### 3.2 核心情境
1. **飯前祝福**：吃飯前對手機念 "Bless this meal"，精靈灑下暖金色光點，哼一聲。
2. **睡前感恩**：睡前說 "Thank you for today"，精靈縮成光球慢慢呼吸，世界轉暗。
3. **兩人共鳴**：兩支手機加入同一個房間，倒數後同時施法，兩隻精靈在同一刻綻放。
4. **成長與演化**：累積 XP 到門檻，精靈從光球孵化成獨一無二的形態，世界多出一種顏色。
5. **心意化為物資**：一天的儀式換到 15 枚精靈幣，預約附近麵包店的一份麵包，自己領或轉成分享券送給需要的人；店員掃碼核銷。
6. **吊墜裡的精靈（概念）**：戒指靠近吊墜，水晶中的小精靈醒來揮手 3–5 秒。

## 4. 產品原則
1. **魔法先於功能**：任何管理性 UI（額度、暫停、申訴、數據）不出現在玩家主畫面，收進設定或管理頁。
2. **中性正向語言**：文案以祝福、感恩、心意、魔法、咒語為主軸；不帶特定宗教，不做信仰判斷。
3. **精靈不說話**：回應＝光影粒子＋可愛音效（哼唧、輕笑）＋（選擇性）一行短字。
4. **誠實標示**：每個效果都帶來源標記；概念影片標 Concept；不放未實測的數字。
5. **AI 不碰帳本**：模型只判斷意圖與產生素材，XP 與點數由規則服務決定。
6. **低門檻、可控成本**：本機能做的不呼叫模型；每人每日上限；全站硬上限。

## 5. 功能需求

格式：`F-編號｜名稱｜優先級（P0 必做／P1 應做／P2 有餘力）｜真實度`，附驗收條件（AC）。原規格需求編號標在括號內以便追溯。

### 5.0 入口與帳號

**F-01｜登入前首頁（Landing）｜P0｜✅**
- 內容：Hero 動態（光球）、30 秒預告片嵌入、「完成度看板」（每項功能標 ✅ Real／🧪 Simulated／🎬 Concept）、"Begin with Google" 按鈕、隱私說明連結。
- AC：未登入可看完整首頁；看板與 §2 一致；手機 360px 無橫向溢出。

**F-02｜Google 登入與同意｜P0｜✅**
- Google OAuth；首次登入顯示隱私說明與同意勾選（GDPR），未同意不可進入。
- 登入即建立 profile（語系、國家、建立時間）。
- AC：登出再登入回到同一隻精靈；拒絕同意時停在說明頁。

**F-03｜孵化（Onboarding）｜P0｜✅（R001）**
- 第一次進入：灰白水彩世界中出現一顆光球，引導使用者念第一句咒語完成孵化並為精靈命名。
- AC：30 秒內可完成；跳過語音可改點選。

**F-04｜設定｜P0｜✅**
- 語言（英文；中文／日文顯示「即將推出」）、音效開關與音量、低動態模式、麥克風權限說明、刪除帳號、隱私資料匯出（P1）。
- 隱藏入口：Demo 時間快轉（F-15）、管理頁（F-40，僅營運角色可見）。
- AC：刪除帳號後資料標記刪除且無法再登入同一精靈。

### 5.1 L1 — 咒語與回應

**F-10｜咒語輸入（語音優先）｜P0｜✅（R002、R003）**
- 按住「施法」按鈕說話（Web Speech API，英文）；放開後顯示辨識文字。
- 輔助輸入：文字輸入、預設咒語點選。
- 不支援語音的瀏覽器：自動改文字＋點選；（P2）Muse Spark 音訊輸入備案。
- AC：Android Chrome、iOS Safari、桌面 Chrome 可語音；拒絕麥克風仍可完成儀式；不保存原始音訊。

**F-11｜意圖判斷管線｜P0｜✅ meta_live / local_rule（R003）**
1. 正規化文字 → 比對本機預設咒語表（命中 → `local_rule`，不呼叫模型）。
2. 未命中且有額度 → 呼叫 Muse Spark，回傳白名單 JSON：`intent`、`confidence`、效果參數。
3. `confidence < 0.6` 或格式錯誤 → 基本回應＋「是這個意思嗎？」選項，不做信仰判斷（T09）。
4. 額度用盡或供應商失敗 → 退回本機規則（A03、A12）。
- 意圖白名單：`bless`、`gratitude`、`calm`、`sleep`、`greet`、`encourage`、`share`、`unknown`。
- AC：每次互動有唯一 `event_id`；畫面顯示來源標記（小圖示）；同一事件重送不重複計獎（T01）。

**F-12｜粒子回應與精靈動作｜P0｜✅（R004）**
- 依 `effect_event`（schema 1.0）在本機播放：palette 1–4 色、motion（halo／swirl／pulse／drift）、spirit_action（nod／curl／bounce／wave／idle）、duration 1–15 秒、粒子 ≤ 1200。
- 固定 seed 可重播；不逐幀呼叫模型；低動態模式改漸層光環。
- AC：點擊後本機效果 p95 < 100ms（目標）；中階 Android 30–60 FPS。

**F-13｜精靈音效｜P0｜✅**
- 寵物式聲音：開心的哼唧、輕笑、睡覺的呼嚕、驚喜的「嗯？」；依意圖與動作播放。
- 音效為免費授權素材或自行製作，於 README 列出授權。
- AC：靜音模式下不播放；音效不含人話。

**F-14｜儀式庫｜P0｜✅（R007–R009 部分）**
- 六類（英文為主）：Meal Blessing、Gratitude、Breath、Bedtime、Together（共同）、Greeting。
- 每類 2–3 句預設咒語＋說明；Breath 含 30 秒呼吸引導動畫；Bedtime 含低刺激暗色效果。
- （P2）感恩日記、提醒。
- AC：每類至少 2 句預設咒語可本機觸發。

### 5.2 L1 — 成長與演化

**F-15｜XP 與成長｜P0｜✅（R005）**
- 規則見 §6。成長頁顯示：目前形態、XP 進度、下一個門檻、歷代形態。
- **Demo 時間快轉**（設定內隱藏開關，標示 Demo）：直接推進到下一門檻以觀看完整演化鏈；快轉產生的 XP／點數標 `demo_fixture`，不進真實帳本。
- AC：每日 XP 上限 60 生效；跨時區不可重領（day_key 依使用者時區）。

**F-16｜AI 隨機演化｜P0｜✅ meta_live（R006、V2-A01）**
- 門檻：0（光球）→ 60 → 150 → 300 → 600 XP，共 5 個形態。
- 管線：Muse Spark 依父形態、seed、成長摘要寫形態描述 → Muse Image 生圖 → SAM 3.1 去背 → 黑底版 → 縮圖（手機 512px、吊墜 54×96 預覽）。
- 形態可為仙子、小動物、花、抽象光體；同條件可得不同合格候選。
- 非同步工作：QUEUED → RUNNING → READY / FAILED，不鎖住 App。
- 失敗：保留原形象與 XP，可重試（T13、A06）。使用者可回退上一版。
- 每人生圖總數上限 3 次（另見 §8）；超過則從預生成形態池中依 seed 選取並標 `demo_fixture`。
- AC：演化完成後首頁、成長頁、吊墜模擬器同步換新形象。

**F-17｜世界隨成長上色｜P0｜✅**
- 世界起始為灰白水彩；每次演化解鎖一種新顏色（共 4 色＋起始光），背景、粒子調色、UI 點綴隨之改變。
- AC：不同階段截圖可明顯看出色彩變化；低動態模式仍保留顏色差異。

### 5.3 L1 — 吊墜模擬器

**F-20｜吊墜模擬器｜P0｜🧪（R023、T14）**
- 畫面中呈現水晶吊墜（依參考設計重新繪製），內部顯示 54×96 黑底虛像版精靈。
- 狀態與行為（對應硬體設計，見 §7）：

| 狀態 | 模擬器表現 | 觸發 |
|---|---|---|
| SLEEP | 微弱 LED 呼吸燈，精靈不顯示 | 預設 |
| RING_WAKE | 播放已存短動畫 3–5 秒，之後冷卻 30 秒 | 「戒指靠近」按鈕 |
| LIVE | 連線中，精靈即時跟隨手機動作 | 「連線」按鈕 |
| RITUAL | 手機儀式的粒子同步到吊墜（吊墜子集：粒子 ≤ 80） | 連線中施法 |
| DOCKED_CHARGING | 吊墜內精靈閉眼吸光；魔法陣底座光紋旋轉亮起 | 「放上魔法陣」按鈕 |

- 呼吸燈設定：亮度、節奏、大小可調；「粒子呼吸」僅在 LIVE 或 DOCKED 時可開。
- 戒指觸發不發點數、不做身分驗證（T10）；持續磁場不重複播放（T11）。
- AC：每個狀態可切換；畫面標示 "Simulated"。

**F-21｜BLE 指令紀錄｜P1｜🧪**
- 模擬器旁可展開「Bluetooth log」，顯示每個動作對應的協定指令（HELLO、TIME_SYNC、PLAY_EFFECT、ASSET_BEGIN/CHUNK/COMMIT、SET_BRIGHTNESS、GET_STATUS、STOP）與實際編碼後的十六進位封包（12 bytes 標頭＋CRC16）。
- 演化完成時示範「素材分段傳送」進度（54×96、RGB565）。
- AC：封包編碼通過 CRC 測試向量（"123456789" → 0x29B1）；程式可於 H2 直接重用。

### 5.4 L2 — 共同儀式

**F-30｜共同儀式房間｜P0（2 人）／P1（4 人）｜✅（R013–R015）**
- 建立房間 → 產生邀請連結與 QR（10 分鐘有效）→ 成員加入並「準備」→ 伺服器排定 start_at（≥ 2 秒後）→ 各機依時鐘偏移同時播放同一 seed 效果。
- 最多 4 人；狀態 CREATED → JOINING → READY → RUNNING → COMPLETED / ABORTED。
- 共同獎勵依 ritual_id＋participant_id 去重；只共享意圖與效果事件，不傳原始語音。
- AC：兩支實機開始時間差 p95 < 200ms（目標，實測記錄）；未受邀者無法加入。

**F-31｜模擬同伴｜P0｜🧪**
- 單人時可加入 1–3 位「模擬同伴」（標示 Simulated），體驗完整流程。
- 模擬同伴不產生任何獎勵。
- AC：單人可完成一次四人魔法陣演示。

### 5.5 L3 — 精靈幣與物資分享

**F-50｜精靈幣錢包｜P0｜✅（V2-E01、E02）**
- 顯示可用點數、凍結點數、到期時間；與 XP 分開顯示，兌換不扣 XP。
- 規則見 §6；活動供給不足（K 不足）時只發 XP（T02）。
- AC：錢包數字與帳本事件加總一致。

**F-51｜物資列表與詳情｜P0｜✅（Demo 商家）**
- 列表：商品、商家、距離（文字地址，不要求定位）、取貨窗口、價格（點數）、剩餘份數。
- 詳情：成分／過敏原、取貨方式、自用或分享選擇。
- 無真實商家時全部標示 Demo（T18）。
- AC：剩餘 0 份時不可預約。

**F-52｜預約（凍結點數）｜P0｜✅（V2-S01）**
- 預約時於同一交易內：扣可用庫存 → 轉為保留庫存、可用點數 → 凍結（HOLD）。
- 最後一份兩人同時搶：一人成功，另一人收到 OUT_OF_STOCK 且無殘留凍結（T03、T17）。
- 預約逾期自動釋放（RELEASE）。
- AC：並行測試通過。

**F-53｜領取券（自用／分享）｜P0｜✅**
- 預約成功產生單次有效領取券（QR＋短碼）。
- 「分享」：產生分享連結，第一個登入並領取的人成為持有人；之後他人無法再領（T04）。
- AC：同一張券只有一位有效持有人。

**F-54｜商家核銷｜P0｜✅（V2-S03）**
- 商家店員以手機開啟核銷頁 → 掃碼或輸入短碼 → 確認交付 → 點數 REDEEM_BURN、庫存出庫。
- 重複核銷回 ALREADY_REDEEMED（T05）；他店券回權限錯誤（T16）。
- AC：核銷頁只對 merchant_staff 角色可見。

**F-55｜「心意如何變成物資」流程頁｜P0｜✅**
- 一頁圖解：咒語 → XP／精靈幣 → 商家承諾供給 → 預約 → 自用或分享 → 核銷；說明點數不可購買、轉讓、兌現。
- 提供影片第三段使用。

**F-56｜申訴入口｜P2｜✅**
- 設定 → 說明與申訴；送出後在管理頁可見。不出現在主畫面。

### 5.6 營運

**F-40｜量化後台（管理頁）｜P0｜✅**
- 僅 platform_operator 可進（設定內隱藏入口或獨立網址）。

### 6.1 XP（永久、只用於成長）

### 6.2 精靈幣（封閉活動點數）
| 參數 | 值 |
|---|---|
| 發放 | 每次合格儀式（含共同儀式）5 點 |
| 每日 | 最多 3 次＝15 點 |
| 物資價格 | 一份 15 點（一天的儀式） |
| 性質 | 依活動分帳、有期限；不可購買、轉讓、交易、兌現；不上鏈 |
| 硬體加成 | 比賽版不啟用（設定檔保留 `hardware_multiplier`，H2 再評估） |
| 現金搭配 | 不啟用 |
| 帳務單位 | 整數十分之一點（5 點＝50 units） |

### 6.3 供給覆蓋（防止發出無法兌現的點數）
- K：活動尚未履行的已承諾供給（點數計價，含可預約與已保留）。
- O：已發出未花費點數；H：已凍結點數；J：發放中保留。
- 硬限制：K ≥ O + H + J。
- 可新增發放：B = max(0, floor(0.8 × K) − O − H − J)，於同一交易內保留。
- B = 0 時只給 XP，畫面提示「今日物資已分享完，精靈仍在成長」。

### 6.4 帳本事件
GRANT_AUTHORIZED → GRANT_POSTED；HOLD；RELEASE；REDEEM_BURN；RESOLUTION（人工調整，需理由）。餘額由不可變事件推得，不覆寫歷史。

## 10. 美術與聲音方向

- **風格**：2.5D 手繪水彩。色彩敘事參考《GRIS》（世界隨成長上色、受限調色盤）；光感參考《Sky 光·遇》（柔光、雲海、暖色逆光剪影）；光影對比參考《雙影奇境》。
- **IP 原則**：生成提示詞只用具體描述（水彩紙紋、逆光剪影、雲海、限色），不寫遊戲名稱；不模仿角色。
- **畫面基礎**：以 v2 的 16 張版型為結構參考（12 手機＋4 桌面），全部重新設計；取代原深藍／薄荷配色。
- **精靈**：預設 Q 版小翅膀仙子方向，形態由 AI 演化決定；需提供黑底版給吊墜。
- **聲音**：寵物式哼唧、輕笑、呼嚕；環境聲極簡；不使用人聲台詞。
