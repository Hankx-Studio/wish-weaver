# 精靈之間：心意召喚 · Fairy Companion: Wish Weaver

> Meta Global AI Developer Hackathon 2026 參賽作品（施工中）

每天 30 秒，用一句真心話養大一隻獨一無二的精靈。
Muse Spark 讀懂你的心意並化為魔法，Muse Image 讓「同一隻」精靈隨你成長，SAM 3.1 把你真實世界的小物變成遊戲寶物。

## 快速開始
```bash
cp .env.example .env   # 填入 MODEL_API_KEY
npm install
npm run dev            # http://localhost:8787
npm test
```
